# Reloaded-NX launcher icon

Original Flowzart Studio artwork for Reloaded-NX. Pedro Soto Almonacid leads and
authors the project's own work, with development assisted by OpenAI Codex.

The 256 × 256 JPEG in this directory is generated entirely from original
geometric drawing coordinates by scripts/generate-launcher-icon.py
(Pillow 11.3.0). There are no fonts, external artwork, screenshots, Pokémon
or Nintendo imagery in the icon. The artwork and generator use the
project's MIT terms. See ../../licenses/Reloaded-NX-MIT.txt.

The NRO embeds this exact JPEG. The operating system and Homebrew Menu
still render their own interface. Engine assets retain their existing
provenance and licenses. The private forwarder art is outside this distribution.
