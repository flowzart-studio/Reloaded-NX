# Reloaded-NX candidate source

This tree contains the Horizon launcher, adapted OpenGMK engine, platform integration,
build scripts, project tests and license texts. Use the exact corresponding-source
archive alongside the installer from GitHub Releases when available. The archive
also supplies vendored Cargo and Rust standard-library sources, SDK source materials
and the bank's preferred-source materials.

Follow [the build guide](BUILDING_CANDIDATE.md) from the extracted source archive
with the pinned external toolchain. [License scope](CANDIDATE_LICENSE_SCOPE.md)
and [notices](THIRD_PARTY_NOTICES.md) apply to the matching components.
