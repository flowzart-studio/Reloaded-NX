# Reloaded-NX 1.6

Native Nintendo Switch homebrew runner based on OpenGMK, developed to run a separately and legitimately obtained compatible copy of Pokémon Reloaded.

**Public documentation edition — scenario B. This repository contains no engine source, installer, NRO or game files. It cannot be built or installed.** Version 1.6 identifies the existing stable runner; this publication introduces no new functional version.

## Project status

The maintainer confirms that 1.6 works on Nintendo Switch. An existing independent source rebuild passed compilation and static checks, but its bytes differ from the stable NRO. Exact reproducibility and hardware equivalence of that rebuilt binary have not been established. This preparation performs no build and changes no runtime files.

The stable line includes configurable controls, right-stick and SL/SR mappings, pointer support, Mega/battle, PC/map/Fly, Safari and casino mappings. These describe the private stable runner, not software delivered by this repository.
