# Reloaded-NX

Native Nintendo Switch homebrew runner for Pokémon Reloaded The Last Beta
1.9.2.2. It integrates an OpenGMK-derived engine, audio, remappable controls,
pointer input and persistence. Supply the EXE and data from your own legitimate
compatible game copy.

Candidate 1.6.1-rc.2 uses the final launcher identity: Reloaded-NX, Flowzart Studio,
version 1.6.1 and the original RX icon. Nintendo Switch acceptance is pending.

Download [v1.6.1-rc.2](https://github.com/flowzart-studio/Reloaded-NX/releases/tag/v1.6.1-rc.2), an experimental pre-release for community testing. Hardware acceptance remains pending for the exact NRO and the optional HOME NSP. Pokémon Reloaded The Last Beta 1.9.2.2 is the reference game version. Compatibility with future game versions remains unverified.
