# Distribution, installation and build status

There is no installer, executable, engine source or build script in this edition. Cloning the repository provides documentation only. There is no supported command to build or install this snapshot. Do not rename the documentation ZIP as an installer or combine it with an unreviewed local archive for upload.

For context, the existing private runner uses hbmenu Application mode and the canonical executable path `sdmc:/switch/reloaded-nx/reloaded-nx.nro`. It requires a compatible, legitimately obtained original game EXE and associated data, supplied separately. These contextual requirements are not an installation procedure for a public download. No firmware compatibility range or Switch 2 support is asserted.

Existing users should retain their working installation and backups. This edition supplies no update that requires copying anything to a microSD. Do not submit saves, keys, game archives or personal diagnostics to public issues. See ../SECURITY.md.

A complete build/install guide must accompany a later rights-cleared engine publication, using the verified corresponding sources and exact dependency notices. See ENGINE_INTEGRATION.md.
