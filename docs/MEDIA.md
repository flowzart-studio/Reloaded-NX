# Screenshots and media

No image is included in this first public edition. Existing gameplay/forwarder captures can contain game art, characters, music, user names, paths or save data; no sufficient image-specific publication permission is established in the available evidence. Owning or taking a screenshot is not treated as permission for all depicted material.

For a future image: record its origin and SHA-256, permission/license for all material depicted, required credit, any editing and a privacy review. An original project-only documentation/technical screen without game imagery may be used once verified. Do not stage a gameplay screenshot, trace game artwork, or label a fabricated mockup as evidence of Nintendo Switch operation.

The maintainer's confirmation of hardware operation remains a written report in this edition. Missing screenshots do not block publishing the documentation repository.
